# Видеосервер для систем видеонаблюдения

**Разрабатываемый сервер** предназначен для приема, обработки, хранения и трансляции видеопотоков низкого разрешения с камер видеонаблюдения. Система обеспечивает стабильную работу 24/7, одновременную обработку большого количества потоков и предоставляет интерфейс для администрирования и просмотра видео.

## Ключевые цели и задачи проекта

*   **Прием потоков:** Поддержка протоколов RTSP, HTTP(опционно), ONVIF(опционно) для подключения IP-камер.
*   **Обработка потоков:**
    *   Декодирование и сжатие видео.   
*   **Хранение архива:** Организация архива видеозаписей с возможностью поиска по времени или событиям.
*   **Трансляция:** Предоставление доступа к видео.
*   **Надежность:** Обеспечение отказоустойчивости и масштабируемости системы.
